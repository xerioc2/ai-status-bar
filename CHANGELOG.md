# Changelog

## 0.1.0

- Status bar reports for Anthropic (Claude), OpenAI (ChatGPT / Codex), GitHub (including Copilot), Cursor, and Perplexity.
- Collapsible Explorer view and editor dashboard with 30 days of reported incident history.
- Provider selection and ordering, automatic checks, and manual refresh.
- Current incident details, affected components, report timestamps, and official status-page links.
- Theme-aware charts, keyboard-accessible history, and explicit unknown/missing coverage.
- Local provider icons and GitHub contribution links. No authentication or telemetry.
